# Freitag AI — сравнение Claude Opus 5.5 через API

**Статус:** подготовлены два необязательных API-провайдера в изолированной тестовой ветке. **Реальных платных запросов не было**, ключей у разработчика нет. Работающая «Мастерская» и старый Worker не менялись.

| | ModelProxy | BotHub |
|---|---|---|
| API chat completions | `https://api.modelproxy.org/v1/chat/completions` | `https://openai.bothub.chat/v1/chat/completions` |
| model | `claude-opus-5-5` (заявлен сервисом) | `claude-opus-5.5` (с официальной страницы BotHub) |
| Cloudflare Secret | `MODELPROXY_API_KEY` | `BOTHUB_API_KEY` |
| Запрос в Freitag AI | `provider:"modelproxy"` | `provider:"bothub"` |
| Запросы к чужому API без ключа | блокируются | блокируются |
| Соединение через /health | бесплатно | бесплатно |
| Подтверждение отправки контекста книги | да | да, отдельно от ModelProxy |

## BotHub — проверенные ссылки

- [Страница BotHub Claude Opus 5.5](https://bothub.chat/ru/claude-opus-5.5)
- [Документация API](https://bothub.chat/api/documentation/ru/our-api/quick-start)
- [Тарифы](https://bothub.chat/ru/main)

На 22 ноября 2026 на странице BotHub указаны **471,43 ₽ за 1 млн входящих токенов** и **2 357,14 ₽ за 1 млн исходящих токенов** (ECO-маршрутизация). Это тарифные заявления сервиса, не проверенные списания. Условные 50 000 входящих + 7 000 исходящих ≈ **40,07 ₽**. Пакет Basic — 250 ₽ за 1 млн Caps — это не безлимитная подписка. Поддержка пользователя подтвердила доступ к моделям Claude с Basic, но **не подтвердила Opus 5.5 отдельно**.

## Включение без изменения продакшена

1. В личном кабинете BotHub **сначала уточнить возможность вызова `claude-opus-5.5` через API на Basic**. Не покупать пакет ради предположения.
2. Создать API-ключ BotHub. Не публиковать ключ, не вставлять в GitHub или чат.
3. В тестовом Cloudflare Worker `freitag-opus-gateway` в Variables and Secrets добавить Secret **`BOTHUB_API_KEY`**. Не изменять `OWNER_UID` и KV binding `BOOKS`.
4. В этот **только тестовый** Worker вручную установить код `proxy/freitag-modelproxy-worker.js` из ветки `feature/freitag-ai-minimal-workspace`. Код включает два провайдера. Старая версия Worker отклонит запрос BotHub еще до генерации — это защитное поведение.
5. Проверка `GET /health` должна показывать `bothubConfigured:true`. Это проверяет лишь наличие ключа и авторизационного UID, а не доступность модели или баланс.
6. В Freitag AI выбрать в настройках **Claude Opus 5.5 · BotHub**. Кнопка «Проверить соединение» бесплатна.
7. Первый платный тест — **без выбранной книги**, короткий запрос, затем в кабинете сверить списание и название модели. Потом одинаковое небольшое литературное задание сравнить с ModelProxy.
8. Для работы с реальной книгой сначала обновить снимок в «Мастерской». Freitag AI показывает время обновления и последние названия глав. При переходе между API-поставщиками заново запрашивает согласие отправить контекст книги.

## Важные ограничения и безопасность

- Ни поддержка BotHub, ни наличие названия модели в каталоге не доказывают качество и происхождение каждого ответа.
- BotHub — посредник, получающий текст запроса. Не отправлять полную неопубликованную рукопись до ознакомления с правилами приватности.
- Подключение через оба API не требует логина в личный Claude, но **не гарантирует**, что провайдер никогда не приостановит API-ключ.
- Стоимость зависит от реального количества входящих/исходящих токенов, внутренних Caps/маршрутизации, кэширования и особенностей тарифа.
- Изменения не развернуты на работающем сайте. Никаких списаний через новую интеграцию еще не было.
