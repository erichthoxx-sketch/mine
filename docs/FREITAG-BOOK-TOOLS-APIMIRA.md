# Freitag AI — доступ к книге через инструменты и резерв ApiMira

**Статус:** изолированная ветка, не развернута в рабочем Worker. Исторические проекты, чаты и исходные Google Docs не изменяются. Дизайн и положение элементов чата не менялись. Отдельная экспериментальная ветка компактного дизайна не объединялась.

## Что делает «Мастерская» в Freitag AI

1. В интерфейсе выбери **Книги**, войди в тот же Firebase аккаунт и свяжи проект с романом из «Мастерской».
2. Перед каждым платным запросом по выбранной книге браузер читает свежий Google Doc и Firestore, а сервер кладет его подтвержденный снимок в общий namespace `BOOKS`. Если документ не прочитан или ревизия не совпала, платный запрос блокируется.
3. Когда модель сочтет нужным, она может самостоятельно запросить из выбранного романа `get_book_context`, `list_chapters`, `read_chapter` (с offset) или `search_book`. Инструменты работают на Cloudflare Worker поверх того же KV, из которого отвечает MCP «Мастерской» для Claude. Это **совместимое по возможностям чтение**, но не прямое MCP-соединение модели с сервером Claude.
4. Никаких write-инструментов, расходов, маркетинга, других книг или произвольных URL модель не получает. Ограничение: максимум три раунда функций, максимум четыре функции на раунд, до 16 000 символов одного фрагмента. Каждое обращение модели к провайдеру может тарифицироваться отдельно.
5. Финальный ответ с инструментами сейчас возвращается после завершения чтения и генерации через совместимый SSE-формат, а не постепенно посимвольно. **Длинную главу и случай обрыва необходимо дополнительно проверить в живой среде.**

## BotHub — основной Opus

- Опция `BotHub · Claude` с моделями `claude-opus-5.5` и `claude-sonnet-5.5`.
- Настроенный секрет `BOTHUB_API_KEY` остается только в Cloudflare Worker `freitag-opus-gateway`.
- Выбор модели на странице настроек автоматически сохраняется. В существующих чатах выбранный провайдер применяется к следующему сообщению.
- Действительный режим тарификации Eco/Pro **не установлен и не подтвержден** настройками ChatGPT/Worker, его нужно оценивать по фактическому списанию в BotHub. Публикуемые API цены BotHub описаны для Eco, но это не доказательство конкретного маршрута.
- Для теста выбери книгу «Развод для черной вдовы», режим «Проверить канон», задай один вопрос с необходимостью прочитать более раннюю главу. После ответа проверь факт по исходнику, а расход в BotHub.

## ApiMira — резерв Opus, пока без оплаты

Документация: https://apimira.com/docs
- `https://apimira.com/v1/chat/completions`
- `GET https://apimira.com/v1/models` — бесплатная проверка каталога
- Model ID: `anthropic/claude-opus-5.5`
- Secret Cloudflare: `APIMIRA_API_KEY` — создавать и вводить **только в Cloudflare**, никогда в JS, скриншотах или переписке.
- `/health` покажет `apimiraConfigured`, а `/preflight?provider=apimira&model=anthropic%2Fclaude-opus-5.5` проверит ключ и наличие модели. Preflight требует действующий Firebase токен владельца; сам чат его отправляет.
- После появления API-ключа его сохраняют в Worker как Secret. Реальную стоимость можно проверить на одной и той же задаче; сначала недорогой запрос без книги, потом фактический вопрос с одной книгой.
- Не обещаем соответствия пользовательского веб-режима Eco/Pro API-тарификации. ApiMira — отдельная компания и отдельный обработчик неопубликованных рукописей.

## Перед развёртыванием

1. Дождись прохождения GitHub Actions, проверь PR и не объединяй несвязанные UI-ветки.
2. В Cloudflare у `freitag-opus-gateway` сохранены `OWNER_UID`, `BOTHUB_API_KEY` и binding `BOOKS`. Проверь, что исходное хранилище `masterskaya_books` не перепутано с другим.
3. В Cloudflare Worker Editor скопируй целиком **один** `proxy/freitag-modelproxy-worker.js` именно из этой ветки; старую версию можно вернуть через Deployments. Не трогай `proxy/books-mcp-worker.js`.
4. Только потом тестируй новую Preview-сборку `freitag-ai-test` (ветка создает отдельный URL). У нее должен быть Preview Service binding `FREITAG_GATEWAY` → `freitag-opus-gateway`.
5. **Чаты IndexedDB привязаны к домену.** Новая Preview-ветка — другой origin, поэтому прежние локальные чаты там могут отсутствовать. Это не удаление данных. Если требуется перенос — сначала экспорт JSON со старого Preview-адреса, затем импорт в новый.
6. При первом тесте не проси целую главу: инструментальный цикл пока не проходил реальную проверку задержек, лимита и денежного расхода. Начни с точного факта в ранней главе; сравни источник и результат.
