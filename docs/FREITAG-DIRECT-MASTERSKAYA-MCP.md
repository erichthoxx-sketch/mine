# Freitag AI ↔ «Мастерская»: прямое MCP-подключение

Текущая рабочая версия описана в [Freitag AI](FREITAG-INFRASTRUCTURE.md). Ниже сохранены сведения о предыдущем этапе подключения.


Статус: черновая ветка, `freitag-opus-gateway` в Cloudflare **не обновлен**. Изменения интерфейса доступны только в изолированной Preview-сборке. Рабочие приложения, рукописи и существующий MCP для Claude не менялись.

## Что именно подключается автоматически

Freitag AI как **MCP-клиент** обращается к существующему серверу
`https://masterskaya-ai.erichtho-xx.workers.dev/mcp` стандартными запросами
`initialize` → `tools/list` → `tools/call`.
Серверный шлюз один раз проверяет Firebase ID-token владельца,
после чего использует секрет `MCP_READ_KEY` только на стороне Cloudflare.
Браузеру, BotHub и ApiMira MCP-ключ не передается.

Доступные **18 read-only инструментов**:
- **Книги:** `list_books`, `get_book_context`, `list_chapters`, `read_chapter`, `search_book`.
- **Маркетинг:** `get_marketing_overview`, `get_book_marketing`, `get_system_status`.
- **Доходы и Литнет:** `get_income_overview`, `get_book_sales`, `get_part_reads`.
- **Директ и Метрика:** `get_direct_overview`, `get_direct_campaign`, `get_direct_report`,
  `get_direct_search_queries`, `get_metrika_sources`, `get_cohorts`, `get_direct_live`.

Каталог и JSON Schema инструментов загружаются с реального MCP-сервера.
Модель выбирает инструмент при необходимости; в коде Freitag AI нет
второй ручной реализации чтения перечисленных данных. Инструменты записи,
удаления и неизвестные инструменты не допускаются. При выборе конкретной
книги сервер принудительно ограничивает чтение ее текста этим романом.
У модели не появляется доступа к исходным API-ключам.

**Автоматическое подключение ≠ автоматическая свежесть всех источников.**
Для выбранной книги Freitag AI перед каждым платным запросом заново читает
Google Docs и записывает актуальный снимок в BOOKS KV. Остальные инструменты
Мастерской могут возвращать сохраненные снимки; `get_system_status` показывает
даты их синхронизации, а отдельные методы Директа умеют получать живую
статистику при наличии пользовательского доступа. Сайт и GitHub-архитектура
не входят в существующие MCP-инструменты; их нельзя обещать без отдельного
источника данных.

## Один обязательный секрет для прямого подключения

В `freitag-opus-gateway` → Settings → Variables and Secrets добавь **Secret**:
`MCP_READ_KEY` = тот же действующий **секрет исходного MCP Worker** `masterskaya-ai`.

**Не присылай значение в чат, GitHub, URL или скриншот.**
Если не знаешь значение старого секрета, его нельзя прочитать из Cloudflare
после сохранения. Согласуй ротацию старого ключа со всеми клиентами, в том
числе Claude, прежде чем менять старый ключ: без этого Claude перестанет
работать.

Уже имеющиеся настройки нового gateway:
- `BOOKS_MCP_URL=https://masterskaya-ai.erichtho-xx.workers.dev/mcp`
- `OWNER_UID` (Secret владельца)
- `BOTHUB_API_KEY` (Secret BotHub)
- `BOOKS` KV binding `masterskaya_books`

### Как проверить без платного запроса

1. После обновления Worker и Cloudflare Preview выбери BotHub · Opus 5.5,
   нажми **Проверить соединение**.
2. UI вызывает защищенный `GET /api/freitag/mcp-tools`, который реально
   проверяет MCP initialization, `tools/list` и отвечает количеством
   разрешенных операций. Ожидается 18 инструментов; проверка не вызывает
   генерацию модели.
3. В новом чате **Без книги** спроси: «Какие источники подключены? Покажи
   дату обновления доходов и расходы по Директу из Мастерской».
   Это уже платная генерация, и возможны несколько обращений к модели
   из-за function calling.
4. В чате с выбранным романом спроси о конкретном факте в ранней главе.
   Прочтение будет проходить через `tools/call` исходного MCP-сервера.

Защищенный Gateway выполняет не больше 3 дополнительных раундов вызовов
инструментов и не больше 8 `tools/call` за запрос. Длинный ответ одного
инструмента обрезается, чтобы ограничить стоимость. Прямой API-клиент
получает **готовый** текст ответа, а не поток отдельных токенов.
Если провайдер не поддерживает формат OpenAI tool_calls, операция даст ошибку;
это нужно проверить реальным коротким запросом до работы над главой.

## Безопасная публикация

- Рабочий исходный MCP `proxy/books-mcp-worker.js` не трогать.
- Код новой версии `proxy/freitag-modelproxy-worker.js` целиком вставить
  в `freitag-opus-gateway` только после успешного CI.
- Оставить точку отката в Cloudflare → Deployments.
- Тестировать отдельно опубликованную Preview ветку `feature/freitag-ai-direct-mcp-all-apps`.
- Разные preview-поддомены разделяют IndexedDB — локальная история не переносится
  автоматически. Это не удаление старых чатов.
- При необходимости ApiMira требует отдельный секрет `APIMIRA_API_KEY`;
  эта настройка не влияет на MCP.
