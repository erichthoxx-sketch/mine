# Freitag AI — тест Claude Opus 5.5 через ModelProxy

**Изолированная тестовая версия.** Исходная «Мастерская», MCP-сервер, приложение «Доходы», рабочий сайт и платные подписки не меняются.

## Что уже изменено в GitHub

- В Freitag AI вместо Polza выбирается **ModelProxy · Claude Opus 5.5**.
- Для ModelProxy используется модель `claude-opus-5-5`, OpenAI-compatible `POST https://api.modelproxy.org/v1/chat/completions`.
- API-ключ хранится **исключительно** как Secret `MODELPROXY_API_KEY` в Cloudflare Worker; в код и браузер не добавляется.
- Перед каждым платным запросом интерфейс бесплатно проверяет `/health`. Если Worker еще отвечает как Polza, отправка запрещена (защита от случайных списаний у старого провайдера).
- Перед первым платным запросом по каждой версии рукописи `/snapshot` бесплатно показывает **общее число частей, названия последних четырех, дату синхронизации**. Автор явно подтверждает отправку контекста посреднику.
- Контекст книги берется из существующего KV binding `BOOKS`, только чтение. Если снимок старше недели, платный запрос не запускается.
- Режимы в этом пилоте ограничивают число генерируемых токенов для контроля стоимости: 750 — проверка канона; 900 — прочие краткие задания; 4500 — сцена. Успешный ответ не доказывает литературное качество.

## Чтобы включить ModelProxy (потребуются действия владелицы в Cloudflare)

1. В кабинете ModelProxy получи **отдельный API-ключ**. Настрой минимальный тестовый баланс/лимит, если доступен. **Не присылай ключ в чат**.
2. В Cloudflare → Workers & Pages → `freitag-opus-gateway` → Settings → Variables and Secrets → Add variable. Имя `MODELPROXY_API_KEY`, тип **Secret**, значение — ключ ModelProxy. Сохрани.
3. Открой **этот же** `freitag-opus-gateway` → Edit code. Замени код на содержимое файла:
   `proxy/freitag-modelproxy-worker.js` из этой GitHub-ветки; Deploy. НЕ изменяй `masterskaya-ai`, `BOOKS`, `OWNER_UID`.
4. Проверка **без списаний**: `https://freitag-opus-gateway.erichtho-xx.workers.dev/health` должна вернуть
   `{"ok":true,"provider":"ModelProxy","model":"claude-opus-5-5","configured":true,"booksConnected":true}`.
5. После успешного GitHub Pages Deploy открой `https://freitag-ai-test.pages.dev/ai/`. Обнови Ctrl+Shift+R, в Настройки выбери ModelProxy, сохрани, нажми «Проверить соединение» (бесплатно). **Первый платный тест — только без проекта**, короткий запрос: «Ответь одним словом: OK».
6. Для теста романа сначала обнови книгу из Google Docs в **«Мастерской» → книга → «Нейросеть» → «Обновить у нейросети»**. При отправке сообщения Freitag AI покажет сохраненные названия последних четырех частей — прежде чем согласиться на списание, проверь, что присутствуют главы 14–15, если это актуальные последние главы.
7. После успешного теста неиспользуемый `POLZA_API_KEY` можно удалить **из `freitag-opus-gateway`**, но только после проверки, что новый Worker развернут. Не трогай отдельные Workers и проект Polza в другом месте.

## Ограничения

- GitHub-коммиты **не обновляют автоматически код `freitag-opus-gateway`**, потому что этот Worker изначально публиковался вручную.
- Без API-ключа ModelProxy и деплоя нового Worker реальный ответ Opus **не проверен**. Тесты используют заглушку API и подписанный тестовый Firebase JWT, **ни копейки не расходуют**.
- Тарифы ModelProxy — заявление сервиса. До сопоставления `usage` в кабинете и полученного текста не считать экономию или качество доказанными.
- Полный текст, отправляемый в ModelProxy, будет обработан сторонним сервисом. Используй небольшой фрагмент и не отправляй неопубликованные материалы, пока не определишься с правилами обработки.
- Отменять или оплачивать подписки Claude, Polza и иных сервисов этот код не может.
