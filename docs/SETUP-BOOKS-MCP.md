# Бесплатный коннектор книг «Мастерской» для Claude

Используется твой существующий аккаунт Cloudflare. **Не менять Worker direct**, к которому уже подключён Яндекс.Директ. Для книг нужен отдельный Worker и бесплатное Cloudflare KV.

## Подключение Cloudflare — один раз

1. Открой https://dash.cloudflare.com → Workers & Pages → Create → создай **новый** Worker, например с именем masterskaya-books. Это не новый аккаунт.
2. В Edit code вставь содержимое файла [proxy/books-mcp-worker.js](../proxy/books-mcp-worker.js) (скопировать полностью) и нажми Deploy.
3. В Cloudflare открой Workers KV (Storage & databases → KV) → Create namespace. Назови namespace masterskaya_books. В настройках нового Worker → Bindings → Add binding → KV namespace выбери его. **Variable name: BOOKS** (большими буквами). Сохрани.
4. Открой «Мастерскую» → любую книгу → «Для нейросети» → «Настроить» → «Скопировать ID». В настройках Worker добавь **Variable (Text) с именем OWNER_UID**, значение — скопированный Firebase ID. Это не пароль: Worker проверяет подпись реального входа в приложение.
5. В «Мастерской» нажми «Создать ключ доступа» → «Скопировать ключ». В настройках нового Worker добавь **Secret с именем MCP_READ_KEY**, значение — созданный ключ. Сохрани его также в менеджере паролей: он понадобится в Claude. **Не вставляй его в GitHub, рукопись и переписку**.
6. Открой в браузере адрес нового Worker с добавленным /health. Должно показать ok:true и configured:true. Если configured:false, проверь BOOKS, OWNER_UID, MCP_READ_KEY.

**Не включай платный тариф Cloudflare.** Free Workers и Workers KV достаточно для личного использования, но есть лимиты. Cloudflare KV Free: 100 000 чтений в день, 1 000 записей в день, 1 ГБ хранения, до 25 МиБ на одно значение. При превышении бесплатных лимитов запросы могут завершаться ошибкой.

## Привязка к Мастерской

1. Скопируй корневой адрес нового Worker (вида https://masterskaya-books.ИМЯ.workers.dev).
2. В книге → «Для нейросети» → «Настроить» вставь адрес **без /mcp**, нажми «Сохранить».
3. Открой книгу → «Подключить книгу». Мастерская заново прочитает Google Документ и сохранит в Cloudflare только эту рукопись и утверждённую Легенду.
4. Когда изменишь главу или каркас — нажми «Обновить у нейросети». Для прекращения доступа — «Отключить». Оригинал на Google Диске не изменится.

Кнопка «Скачать контекст» работает даже без Cloudflare: это один файл для загрузки в чат или проект ChatGPT/Claude.

## Подключение Claude

1. Claude → Customize → Connectors → Add → Custom → Web.
2. Название: «Мастерская — книги». URL: **АДРЕС_НОВОГО_WORKER/mcp**.
3. Аутентификация: **No sign in / Без входа**; в разделе Request headers добавь заголовок **X-Master-Key** со значением того же ключа, который был добавлен как Secret MCP_READ_KEY.
4. Сохрани подключение и включи его для нужного диалога или проекта.
5. Напиши: «Покажи мои книги из Мастерской. Используй только роман “Развод для черной вдовы”, прочитай канон и главы 1–3».

Все книги, которые ты сама подключила, видны через один коннектор. Книги, которые не подключены, ему недоступны. В Claude Free можно добавить один собственный коннектор.

## Принципы защиты

- Нейросеть может **читать, но не менять** рукопись, каркас и героев. Инструментов записи нет.
- Загружать, обновлять и удалять копии может только твой Firebase-аккаунт, проверенный по цифровой подписи. У нейросети отдельный ключ **только на чтение**.
- Копия отправленной книги хранится в **Cloudflare KV**, а прочитанные фрагменты передаются Claude. Она не опубликована для всех, но это дополнительные облачные сервисы. Для особо чувствительных текстов используй только локальный экспорт.
- При отключении книга удаляется из KV, но распределённому кэшу может потребоваться время, а уже переданные в прошлые чаты фрагменты не отзываются.
- Изменения прямо в Google Docs не появляются автоматически: только после «Обновить у нейросети» в Мастерской.
- При утрате ключа создай новый, замени MCP_READ_KEY в Cloudflare и X-Master-Key в Claude.
- Не менять proxy/direct-worker.js и существующий Worker direct.
