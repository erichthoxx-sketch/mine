# Единый контекст для разных нейросетей — бесплатно

Один Cloudflare Worker по стандарту MCP обслуживает контекст четырёх приложений: **Книги, Маркетинг, Доходы, Яндекс.Директ**. Внешние нейросети получают только чтение. Worker с рекламой direct и сайт lanafreitag.ru **не трогаем**.

Текущий статус: код готов в GitHub, но пока **не развернут** в Cloudflare. Кнопка «Подключить весь контекст» находится в «Мастерская → Настройки → Нейросети». После настройки она за один запуск соберёт данные из всех разделов.

## Один раз настроить Cloudflare

1. В существующем аккаунте https://dash.cloudflare.com → **Workers & Pages → Create application → Create Worker**. Имя **masterskaya-ai**, затем **Deploy**. **Не создавать новый аккаунт** и не заменять уже работающий Worker **direct**.
2. У нового Worker открой **Edit code**, полностью замени шаблон кодом из [proxy/books-mcp-worker.js](../proxy/books-mcp-worker.js) и нажми **Deploy**.
3. В меню Cloudflare **Storage & databases → KV** создай один namespace **masterskaya_books**. У Worker **masterskaya-ai → Settings → Bindings → Add → KV namespace**, выбери namespace и задай имя переменной **BOOKS**.
4. В «Мастерской → Настройки → Нейросети → Настроить» нажми **Скопировать ID**. В настройках нового Worker добавь текстовую переменную **OWNER_UID** с этим ID. Это не секрет, а идентификатор владельца; подлинность входа сверяется с подписью Firebase.
5. В том же окне нажми **Создать ключ доступа**. Ключ скопируй и сохрани в менеджере паролей. В Cloudflare добавь **Secret** с именем **MCP_READ_KEY** и значением созданного ключа. Не публиковать его в GitHub или переписке.
6. Открой https://masterskaya-ai.ВАШ_SUBDOMAIN.workers.dev/health — должно быть ok:true, configured:true. Не указывай чужой домен; реальный поддомен виден в панели Cloudflare. Доступные планы — бесплатные Workers и KV. Не переходи на платный тариф.

## Одна кнопка в Мастерской

1. В «Мастерская → Настройки → Нейросети → Настроить» вставь базовый адрес нового Worker, без пути /mcp, и сохрани.
2. Нажми **Подключить весь контекст**. При первом подключении подтверди отправку копий рукописей и коммерческой статистики в закрытый Cloudflare KV.
3. После завершения в настройках появится дата обновления, число книг и предупреждение, если какой-то раздел не удалось передать.
4. После изменения глав или обновления статистики нажимай **Обновить весь контекст**. Это снимок на момент нажатия, не непрерывный доступ к твоей базе. Можно **Отключить всё**: копии в Cloudflare удалятся, оригиналы останутся.

Источники: Google Docs — написанные главы, Легенда, синопсис; Мастерская — маркетинговые карточки и идеи; Доходы — продажи, роялти, кампании и расходы; Директ — сохранённые данные кампаний и Метрики из Firestore. Все суммы в рублях. Контекст **не** включает пароли, личные контакты и токены API.

Работает **без Claude и без MCP**: в «Мастерская → Настройки → Нейросети» есть **«Скачать для любой нейросети»**. Эта кнопка создаёт один локальный Markdown-файл с контекстом всех книг и очищенными от ключей сведениями о маркетинге, доходах и Директе. Файл прикрепляется к выбранному чату или проекту вручную — если модель принимает Markdown. Для меньших файлов в карточке каждой книги есть «Скачать контекст». Не все модели смогут прочитать очень большой файл целиком из-за лимитов контекстного окна.

## Подключение к нейросетям (по возможностям сервиса)

1. Claude → **Customize → Connectors → Add custom connector** (или «Custom → Web»).
2. Название: **Мастерская AI**; URL: **https://masterskaya-ai.ВАШ_SUBDOMAIN.workers.dev/mcp**.
3. Authentication: **No sign in**. В **Request headers** добавь **x-api-key** и значение секретного ключа из шага 5. Claude поддерживает запросные заголовки для постоянных ключей.
4. Подключи коннектор в нужном диалоге/проекте. Пример вопроса: «Посмотри состояние источников через get_system_status и сравни продажи „Альпийского развода“ с расходами на рекламу за октябрь. Не делай выводов, если данных нет».

Поддерживаются x-api-key, прежний X-Master-Key и Authorization: Bearer. Для максимальной совместимости выбирайте x-api-key. После изменения кода Worker в GitHub обновите его вручную в Cloudflare — исходный код в репозитории не разворачивается автоматически. Claude поддерживает собственные удалённые MCP-подключения с фиксированными заголовками. Другие нейросети могут предъявлять собственные требования к аутентификации. ChatGPT Plus сейчас не поддерживает установку собственного MCP напрямую; используйте загрузку файлов. Некоторые возможности пользовательских MCP в Gemini доступны только в отдельных странах и аккаунтах. Ни одна внешняя нейросеть не подключается к вашему личному проекту автоматически — после настройки Worker требуется отдельное действие в её интерфейсе.

## Безопасность и ограничения

- **Нейросеть может читать, но не изменять** книгу, Легенду, рекламу или доходы. Worker проверяет личный ключ. Передача копий из Мастерской проверяет подписанный Firebase ID token и OWNER_UID.
- В Cloudflare хранятся **копии выбранного контекста**; это другой облачный сервис, не Google Drive. Отправленные нейросети фрагменты могут остаться в истории чата. Отзыв доступа не удаляет историю.
- При бесплатных тарифах действуют квоты Cloudflare KV; при исчерпании операция может завершиться ошибкой. Кнопка не должна сообщать об успехе, если отправка не состоялась.
- Синхронизация Директа использует **последний сохранённый снимок** данных, не делает рекламных операций и не вызывает платные API.
- Нейросеть запрашивает **только нужные разделы**, а не загружает все романы и отчёты в память одним огромным текстом.
- Если коннектор не подключается, проверь /health, затем переменные BOOKS, OWNER_UID, MCP_READ_KEY, базовый адрес и заголовок x-api-key.
