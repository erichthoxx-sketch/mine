# Как подключить «Директ» (один раз, ~30 минут + ожидание одобрения Яндекса)

Приложение: https://erichthoxx-sketch.github.io/mine/direct/
Пока ничего не подключено, там можно нажать «Посмотреть на примере» — и потренироваться без денег.

## Шаг 1. Переходник на Cloudflare (бесплатно, без карты)

Яндекс не пускает браузерные приложения в Директ напрямую. Переходник — маленькая программа на Cloudflare:
он только передаёт запросы приложения в Директ и обратно, ничего не хранит. Пользоваться им можно только с вашего сайта.

1. Зарегистрируйтесь на https://dash.cloudflare.com/sign-up (почта и пароль).
2. Слева **Compute → Workers & Pages** → синяя кнопка **Create application** → **Start with Hello World!**
3. Имя — `direct` → **Deploy**.
4. Нажмите **Edit code**, удалите всё в окне и вставьте текст файла
   [`proxy/direct-worker.js`](../proxy/direct-worker.js) (кнопка «Raw» → выделить всё → скопировать) → **Deploy**.
5. Скопируйте адрес вида `https://direct.ВАШЕ-ИМЯ.workers.dev` — он понадобится в Настройках приложения.

## Шаг 2. Приложение Яндекса (даёт «ключ» для входа)

1. Откройте https://oauth.yandex.ru/client/new (войдите в тот аккаунт Яндекса, где ваш Директ).
2. Название — любое, например «Директ Ланы». Платформа — **Веб-сервисы**.
3. **Redirect URI**: `https://erichthoxx-sketch.github.io/mine/direct/` (точно так, со слешем в конце).
4. Доступ к данным: найдите **Яндекс Директ** → «Использование API Яндекс Директа» (`direct:api`).
5. Создайте приложение и скопируйте **ClientID**.

## Шаг 3. Заявка на доступ к API Директа

1. В кабинете Директа откройте раздел **API** (обычно он в меню «Инструменты» или в настройках; если не видно — поиск по странице помощи «заявка на доступ к API»).
2. Примите условия, создайте заявку, укажите **ClientID** из шага 2.
   Цель — «управление собственными рекламными кампаниями».
3. Ждите одобрения (обычно от нескольких часов до нескольких дней). Пока ждёте, можно включить **песочницу**
   (там же, в разделе API) — тренировочный Директ без денег — и отметить «Песочница» в Настройках приложения.

## Шаг 4. Вход в приложении

1. https://erichthoxx-sketch.github.io/mine/direct/ → ⚙ Настройки.
2. Вставьте адрес переходника и ClientID → «Сохранить».
3. «Войти через Яндекс» → разрешить доступ. Готово: приложение само загрузит кампании.

Ключ Яндекса хранится в ваших данных (как ключ Todoist), в код и на GitHub не попадает.
Когда срок ключа подходит к концу, приложение напомнит войти заново.

## Шаг 5 (по желанию). Яндекс Метрика — видеть покупки, а не только клики

У владелицы на Литнете стоит счётчик Метрики автора. Подключение (в приложении: ⚙ Настройки → «Яндекс Метрика»):
1. https://oauth.yandex.ru/ → приложение «Директ Ланы» → «Редактировать» → «Доступ к данным» → **Яндекс Метрика** →
   «Получение статистики, чтение параметров своих и доверенных счётчиков» (`metrika:read`) → сохранить.
2. Обновить переходник в Cloudflare (новый код — кнопка в Настройках; версия 2 умеет Метрику, только чтение).
3. Войти через Яндекс заново (новый ключ получит доступ к Метрике).
4. «Найти мои счётчики» → выбрать счётчик и цели (★ — главная, обычно покупка).

Конверсии по целям считает сам Директ (Reports API, параметр Goals, атрибуция LSC). Метрика через переходник даёт
поведение на странице книги по кампаниям Директа (визиты, отказы, глубина, время).
Чтобы Директ видел покупки, счётчик должен быть привязан к кампании — приложение подскажет и привяжет по кнопке.

## Если у Яндекса сбой

Приложение повторяет запрос, а если Яндекс так и не ответил — показывает последние сохранённые данные и само пробует
снова через 15 минут. Дни сбоя, отмеченные в «Доходах» (событие «Сбой»), не участвуют в выводах о покупках.

## Безопасность

- Бюджет и дневной лимит приложение не меняет — ставьте их в кабинете Директа. Тогда больше лимита не потратится.
- Ставка дороже предела из Настроек (по умолчанию 50 ₽) не ставится — ни вами по ошибке, ни по плану ИИ.
- Любое изменение — только после «Применить» (или галочки в плане ИИ) и записывается в «Историю».

## ИИ-таргетолог (Claude или ChatGPT)

«ИИ-помощник» → выберите Claude или ChatGPT → вставьте ключ API → «Подключить».
- Ключ Claude — https://console.anthropic.com/settings/keys, ChatGPT — https://platform.openai.com/api-keys.
  Это оплата за использование (не подписка на чат): обычно десятки рублей за один разбор.
- ИИ разбирает кампании сам раз в день (когда открываете приложение) или по кнопке «Разобрать сейчас» и предлагает план.
  **Применяется только то, что вы отметили** — сам ИИ в кабинете ничего не меняет.
- «Сменить на ChatGPT / Claude» — переключение одной кнопкой, «Отключить» — выключить (ключ сохранится).
- Запросы к нейросети идут через ваш переходник — после обновления приложения вставьте в Cloudflare новый код переходника (версия 3).
