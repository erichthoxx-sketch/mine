# Мастерская в личном ассистенте GPTunneL

Отдельный Cloudflare Worker читает один снимок, который уже синхронизирован из Мастерской. Он подключается к тому же KV, что и действующий `masterskaya-ai`, и выполняет только `get` с ключом `book:<выбранный ID>`. Обновления Мастерской поступают через её обычную синхронизацию. После удаления снимка в Мастерской доступ прекращается, когда обновление KV распространится. Подключение не меняет инструкцию ассистента и не сокращает ваши промпты.

## Подключение

В терминале macOS, Linux или WSL с Node.js 22+ откройте папку репозитория с этой веткой и запустите:

```sh
node scripts/setup-gptunnel-books.mjs
```

Команда попросит ввести три идентификатора и ключ. Подготовьте:

- Код ассистента из **GPTunneL → Ассистенты → ваш ассистент → Настройки**. Тип ассистента должен быть **Приватный**. Если там уже есть MCP, команда остановится, поскольку GPTunneL заменяет весь блок MCP при обновлении.
- ID пространства KV из **Cloudflare → Storage & databases → KV → `masterskaya_books`**. Проверьте, что действующий Worker Мастерской использует именно это пространство в привязке `BOOKS`.
- ID выбранной книги из списка ключей в этом пространстве KV. Введите часть её ключа после `book:`. Строку со значением снимка открывать или копировать не нужно.
- Личный API-ключ из **GPTunneL → профиль → API**. Ввод в терминале скрыт. Ключ служит для запросов конфигурации ассистента и не передаётся Worker.

Wrangler откроет в браузере вход в Cloudflare. Выберите аккаунт, где находится Мастерская. Команда создаст новый Worker со случайным суффиксом, сгенерирует отдельный токен `GPTUNNEL_WORKSHOP_KEY` и запишет его как Cloudflare Secret. Она проверит ответ `401` без токена и список инструментов с токеном. Затем отправит GPTunneL только ID ассистента и блок `mcp` с адресом Worker и `accessToken`. Существующие Worker, привязки и секреты не используются для авторизации через GPTunneL. Команда не запускает модели и не обращается к `assistant/chat`.

После подключения в **GPTunneL → Настройки ассистента → MCP** нажмите **Проверить**. Основной адрес в команде заканчивается на `/sse`, как в примере Assistant API. Для Streamable HTTP у того же Worker есть `/mcp`. До первого подключения можно передать команде `--streamable`, чтобы выбрать этот маршрут. Client ID, Client Secret и Scope относятся к OAuth. Передачу статического токена UI не документирует. Платформа документирует поле `mcp[].accessToken` в Assistant API.

## Инструменты

| Инструмент | Пример аргументов | Результат |
| --- | --- | --- |
| `list_books` | `{}` | Выбранная книга или пустой список, если её снимка ещё нет |
| `get_book_context` | `{"book_id":"demo","limit":4000}` | Фрагмент канона, синопсиса, плана и персонажей из снимка |
| `list_chapters` | `{"book_id":"demo"}` | Порядок, названия и размеры глав |
| `read_chapter` | `{"book_id":"demo","chapter":1,"offset":0,"limit":4000}` | Фрагмент главы с указателем `nextOffset` |
| `search_book` | `{"book_id":"demo","query":"маяк"}` | Фрагменты глав с буквальным совпадением без учёта регистра |

Полные схемы аргументов MCP возвращает в `tools/list`. Для очередной страницы канона или главы передайте возвращённый `nextOffset` в `offset`. Смещения считаются в единицах UTF‑16. Текст берётся из последнего синхронизированного снимка. Отдельные разделы маркетинга, финансов, рекламы и служебные ключи недоступны. У ассистента нет операций записи.

## Отзыв доступа

Чтобы немедленно прекратить новые чтения, удалите секрет `GPTUNNEL_WORKSHOP_KEY` у **нового** Worker в **Cloudflare → Workers & Pages → новый Worker → Settings → Variables and Secrets**. Без ключа маршруты возвращают `401`. В GPTunneL соединение удаляется очисткой блока MCP или через `assistant/update` с `mcp: []`. Уже использованные фрагменты могут сохраняться в истории GPTunneL. Markdown книги, секреты и реальные ID не следует сохранять в репозитории, скриншотах или логах.

## Проверка

`npm test` проверяет новую авторизацию, обе схемы MCP-транспорта, данные книги, отказ для чужого ID, попыток записи и чтения служебных разделов. Оба транспорта дополнительно проверены официальным MCP SDK в локальном Cloudflare Worker с вымышленным снимком. Совместимость с фактической кнопкой «Проверить» и передачу `Authorization` клиентом GPTunneL нужно подтвердить после подключения в личном аккаунте.
