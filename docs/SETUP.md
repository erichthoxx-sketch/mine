# Настройка с нуля — пошагово

Всё делается мышкой в браузере, командная строка не нужна. Потребуется около 30–40 минут один раз.
Что получится: сайт по адресу вида `https://erichthoxx-sketch.github.io/mine/`, вход по вашей почте, данные синхронизируются между телефоном и компьютером.

Как это устроено (чтобы было не страшно):
- **GitHub** хранит код и показывает сайт. Ваши продажи и доходы туда **не попадают**.
- **Firebase** (сервис Google) хранит ваши данные и проверяет пароль. Бесплатного тарифа хватит на годы.

Названия кнопок в чужих сервисах иногда меняются. Если кнопка названа чуть иначе — ищите самую похожую по смыслу.

---

## Шаг 1. Код должен оказаться в основной ветке GitHub
Сайт публикуется из ветки `main`. Напишите Claude: «слей код в main» — он сделает это сам. Вам ничего нажимать не нужно.

## Шаг 2. Создайте проект в Firebase
1. Откройте https://console.firebase.google.com и войдите своим аккаунтом Google (Gmail).
2. Нажмите **«Создать проект»** (Create a project).
3. Название — любое, например `author-income`. Нажмите «Продолжить».
4. Переключатель **Google Analytics выключите** (он не нужен). Нажмите **«Создать проект»**, дождитесь «Ваш проект готов», нажмите «Продолжить».

## Шаг 3. Добавьте «веб-приложение» и скопируйте настройки
1. На главной странице проекта нажмите значок **`</>`** (Web).
2. Псевдоним приложения — например `tracker`. Галочку «Firebase Hosting» **не ставьте**. Нажмите **«Зарегистрировать приложение»**.
3. Появится блок кода с `const firebaseConfig = { apiKey: "...", authDomain: "...", ... }`. **Скопируйте этот блок целиком** (кнопка копирования рядом) и пришлите Claude в чат — он вставит его в файл `js/firebase-config.js`.
   Это не пароль: эти значения видны на любом сайте на Firebase, защита обеспечивается правилами из шага 6.
4. Нажмите «Продолжить к консоли».

## Шаг 4. Включите вход по почте
1. Слева: **Сборка (Build) → Authentication**. Нажмите **«Начать»** (Get started).
2. Вкладка **«Способ входа»** (Sign-in method) → **«Электронная почта/пароль»** (Email/Password).
3. Включите первый переключатель (**Enable**). Второй («Вход по ссылке») оставьте выключенным. **Сохранить**.

## Шаг 5. Создайте базу данных
1. Слева: **Сборка → Firestore Database** → **«Создать базу данных»**.
2. Расположение: выберите **`eur3 (europe)`** (или другое в Европе — это ближе к вам и быстрее). Нажмите «Далее».
3. Режим: **«Рабочий режим»** (Production mode). Нажмите **«Создать»**.

## Шаг 6. Правила безопасности — чтобы данные видели только вы
1. В Firestore откройте вкладку **«Правила»** (Rules).
2. Удалите всё, что там есть, и вставьте содержимое файла `firestore.rules` из репозитория:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
3. Нажмите **«Опубликовать»**.

## Шаг 7. Разрешите адрес сайта
1. **Authentication → Настройки (Settings) → Авторизованные домены** (Authorized domains).
2. Нажмите **«Добавить домен»** и впишите `erichthoxx-sketch.github.io`. Сохраните.

## Шаг 8. Включите публикацию сайта на GitHub
1. Откройте https://github.com/erichthoxx-sketch/mine → **Settings** (вкладка справа) → слева **Pages**.
2. В разделе **Build and deployment → Source** выберите **«GitHub Actions»**.
3. Если GitHub пишет, что для приватного репозитория Pages недоступны: **Settings → внизу «Danger Zone» → Change visibility → Make public**. В репозитории лежит только код, личные файлы исключены (`.gitignore`), а ваши данные хранятся в Firebase.
4. Откройте вкладку **Actions**. Должен идти (или завершиться зелёной галочкой) запуск «Публикация сайта». Если его нет, выберите его слева и нажмите **Run workflow**.
5. Когда появится зелёная галочка, адрес сайта виден в **Settings → Pages** (сверху: «Your site is live at…»).

## Шаг 9. Первый вход
1. Откройте сайт. Введите свою почту и придумайте пароль (от 6 символов) → **«Создать аккаунт»**.
2. Вкладка **«Данные»** → **«Выбрать файл Statistic.csv»** → проверьте предпросмотр (должно быть «✔ Сумма строк … совпадает с «Итого»») → **«Загрузить»**.
3. Позже загрузите `dohody.csv` (там же), добавьте книги, кампании и недельные отчёты.

> Создавать второй аккаунт не нужно. Один и тот же вход используйте и на телефоне, и на компьютере.

## Шаг 10. Значок на телефоне
- **iPhone (Safari):** кнопка «Поделиться» → **«На экран „Домой“»**.
- **Android (Chrome):** меню ⋮ → **«Добавить на главный экран»** / «Установить приложение».

---

## Каждый день
- Раз в несколько дней: кабинет Литнета → выгрузить Statistic.csv → «Данные» → «Выбрать файл». Повторные загрузки безопасны: дубли не появляются.
- Раз в неделю: вставить отчёт таргетологов на странице кампании («Вставить таблицу» или «+ Неделя»).
- Раз в месяц: внести комиссию Rocket («Финансы» → «Rocket и расходы за месяц») и скачать резервную копию («Данные» → «Скачать копию»).

## Если что-то не так
- **Забыли пароль:** на экране входа впишите почту и нажмите «Забыли пароль?» — придёт письмо.
- **На сайте белая страница или «Не удалось запустить»:** проверьте, что значения в `js/firebase-config.js` вставлены без «ВСТАВЬТЕ» и что выполнены шаги 4–6.
- **«Missing or insufficient permissions» / данные не сохраняются:** проверьте шаг 6 (правила опубликованы) и что вы вошли.
- **Сайт не обновился после изменений:** вкладка Actions → дождитесь зелёной галочки и обновите страницу (на телефоне — закройте и откройте вкладку).
- **Бесплатные лимиты Firebase:** 50 000 чтений и 20 000 записей в день; при вашем объёме данных вы их не достигнете. Если когда-нибудь Firebase потребует перейти на платный тариф, скачайте резервную копию — все данные переносятся.
