# Как запустить приложение — простая версия

Всё остальное сделает Claude. От вас — две короткие части, только мышкой, без программ.

---

## Часть 1. GitHub (2 минуты)
Нужно, чтобы GitHub показывал приложение как сайт.

1. Откройте https://github.com/erichthoxx-sketch/mine/settings
2. Прокрутите страницу **в самый низ**, до красной рамки «Danger Zone».
3. Нажмите **Change visibility** → **Change to public** → подтвердите (GitHub попросит нажать ещё пару кнопок «I want to make this repository public» / «I have read and understand…» — нажимайте).
   *Это безопасно: в репозитории только код программы. Ваши продажи и доходы туда не попадают — они будут храниться отдельно, в защищённой базе.*
4. Слева в меню нажмите **Pages**.
5. В пункте **Source** выберите **GitHub Actions**. Всё, больше ничего не нажимайте.
6. Напишите Claude: **«GitHub готов»**.

## Часть 2. Firebase — база данных и вход по почте (10–15 минут)
Нужно, чтобы данные были одни и те же на телефоне и компьютере.

1. Откройте https://console.firebase.google.com и войдите своей почтой Gmail.
2. Нажмите **«Создать проект»** (или «Create a project» / «Get started»). Название — `dohody`. Дальше **«Продолжить»**. Google Analytics — **выключить**. **«Создать проект»** → подождите → **«Продолжить»**.
3. На главной странице проекта найдите круглый значок **`</>`** и нажмите его. Название — `dohody`. **«Зарегистрировать приложение»**.
4. Появится серый блок текста, начинающийся с `const firebaseConfig = {`. **Скопируйте его и пришлите Claude.** Это не пароль, его безопасно отправлять.
5. Слева выберите **Authentication** (может быть в разделе «Сборка» / «Build») → **«Начать»** → **«Электронная почта/пароль»** → включите **первый** переключатель → **«Сохранить»**.
6. Слева выберите **Firestore Database** → **«Создать базу данных»** → расположение любое европейское (например, `eur3`) → **«Рабочий режим»** (Production) → **«Создать»**.
7. Там же откройте вкладку **«Правила»** (Rules), сотрите всё и вставьте:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```
   Нажмите **«Опубликовать»**. *(Это значит: каждый видит только свои данные.)*
8. Снова **Authentication** → вкладка **«Настройки»** (Settings) → **«Авторизованные домены»** → **«Добавить домен»** → впишите `erichthoxx-sketch.github.io` → **«Добавить»**.

Если какой-то экран выглядит иначе — сделайте скриншот и пришлите Claude.

## После этого
Claude пришлёт ссылку вида `https://erichthoxx-sketch.github.io/mine/`. Дальше Claude не нужен:
1. Откройте ссылку → впишите почту и придумайте пароль → **«Создать аккаунт»** (один раз).
2. Вкладка **«Данные»** → **«Выбрать файл Statistic.csv»** → **«Загрузить»**.
3. На телефоне откройте ту же ссылку и войдите той же почтой. Чтобы был значок как у приложения:
   iPhone (Safari) — «Поделиться» → «На экран „Домой“»; Android (Chrome) — меню ⋮ → «Добавить на главный экран».

## Обычное пользование
- Раз в несколько дней: скачать Statistic.csv в кабинете Литнета → «Данные» → загрузить. Повторы не задваиваются.
- Раз в неделю: на странице кампании → «Вставить таблицу» (скопировать строки из отчёта таргетологов).
- Раз в месяц: «Финансы» → «Rocket и расходы за месяц»; «Данные» → «Скачать копию».
- Забыли пароль: на экране входа впишите почту → «Забыли пароль?».

## Бесплатно ли это
Да. GitHub Pages бесплатен для открытых репозиториев. Бесплатного тарифа Firebase (50 000 чтений в день) с большим запасом хватит на годы такого использования.
