# Pinterest в Мастерской — MVP (тестовая ветка)

Маршрут: /marketing/pinterest. Lazy import только при открытии вкладки, без правок общего store, Firestore, рукописей, прокси и публикации сайта. Данные локальны, отдельный ключ на UID. Не хранить токены и рукописи в localStorage или git. Источник — только выбранные метаданные книг; цитата из поля маркетинга, требует проверки. Никаких запросов в Pinterest или AI API. Предлагаемые идеи — эвристики, не живые тренды. Ручное подтверждение публикации, не статус от Pinterest. Готовность профиля — ручной чек-лист.

Следующий этап после проверки интерфейса: отдельное защищенное серверное хранилище с авторизацией и синхронизацией; загрузка готовых изображений в приватное хранилище; проверка разрешений Pinterest Business / API / RSS по официальной документации и реальному аккаунту; экспорт только одобренных пинов, идемпотентность, лимиты, отключаемый планировщик. Не публиковать автоматически до подключения и явного утверждения. Аналитика — только фактическая после авторизации. Отдельный PR перед внедрением серверной части.
