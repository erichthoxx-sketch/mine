# Pinterest — второй этап (тестовая ветка)
Вкладка открывается лениво, не изменяет WCOLLS, общие правила Firebase, сайт или рукописи. Оригиналы JPG/PNG/WebP сохраняются в отдельном IndexedDB по UID и ID пина, предпросмотр — object URL. Облако: users/{uid}/pinterest_private/workspace; применяется существующее правило доступа только владельцу UID. Ревизия в транзакции предотвращает молчаливую перезапись другого устройства. Только явное сохранение/загрузка; оригиналы НЕ синхронизируются. Архив до 600 КБ, экспорт JSON. ИИ — экспорт подготовленного запроса и проверяемый импорт JSON; автоматического вызова модели нет. Аналитика — ручной ввод, без доступа к Pinterest. Не включать публикацию до проверки официального доступа API/RSS и ручного теста UI.
